# Spartan Design VIQRC Curriculum

A year-long 2026-2027 competitive VEX IQ curriculum for Mary R. Stauffer Middle School and Ms. Lang.

## Site contents

- Six grading-period curriculum sprints
- Six-person competition teams with lead/backup drivers, programmers, and strategists
- Weekly instructional rhythm and assessment plan
- VIQRC Level Up strategy lens and official resources
- Downloadable Canvas course shell and team-roster template

## Local review

Requires Node.js 22 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

## GitHub Pages

The workflow in `.github/workflows/pages.yml` builds and publishes the static site after changes are pushed to `main`.

In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**. The published site will appear at:

`https://spartandesign.github.io/spartandesign-viqrc/`
